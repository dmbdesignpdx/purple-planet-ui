# Purple Planet UI

Another UI component library and design system for React applications.

Components are built on [Ark UI](https://ark-ui.com) primitives, styled with [Panda CSS](https://panda-css.com), and developed and documented in [Storybook](https://storybook.js.org). The library is early, and currently has two components:

- **Button**: `solid`, `outline` and `ghost` variants in `sm`, `md` and `lg` sizes.
- **Card**: a multi-part component with `Root`, `Header`, `Body` and `Footer` slots.

## Getting started

This project uses [bun](https://bun.sh).

```bash
bun install
bun run codegen   # generates ./styled-system, which components import from
bun run dev       # Storybook on http://localhost:6006
```

`styled-system/` is generated and git-ignored, so run `bun run codegen` on a fresh checkout and again whenever `panda.config.ts` or a recipe changes.

## Scripts

| Command             | What it does                                        |
| ------------------- | --------------------------------------------------- |
| `bun run dev`       | Starts Storybook on port 6006                       |
| `bun run story`     | Builds a static Storybook to `storybook-static/`    |
| `bun run gen`       | Regenerates `styled-system/` from `panda.config.ts` |
| `bun run lint`      | Lints and checks import order with Biome            |
| `bun run format`    | Formats with Biome                                  |
| `bunx tsc --noEmit` | Typechecks the project                              |
| `bunx vitest run`   | Runs the stories as tests in headless Chromium      |

Install the browser once before running tests:

```bash
bunx playwright install chromium
```

## Project structure

```text
src/
  components/<name>/   <name>.recipe.ts, <name>.tsx, <name>.stories.tsx
  utils/               typed recipe helpers (define-recipe.ts, recipe-types.ts)
  fonts/               Inter variable font
  global.css           cascade layer order
  index.ts             public exports
theme/                 design tokens: colors, fonts, sizes, spacing, radii, text styles
.storybook/            Storybook config, theme switcher and a11y settings
styled-system/         generated by Panda (git-ignored)
panda.config.ts        Panda config and recipe registration
```

## Theming

- Tokens are defined in `theme/` and wired into `panda.config.ts`.
- Components use semantic color tokens by name, such as `primary`, `secondary`, `background` and `surface`, each with a `.text` variant. These switch between light and dark values.
- Dark mode is class-based. Panda's `_dark` condition matches a `dark` class on an ancestor. In Storybook, use the theme switcher in the toolbar.

## Adding a component

1. Create `src/components/<name>/` with a recipe, the component and its stories.
2. Write the recipe with `defineRecipe` (a single recipe) or `defineSlotRecipe` (a multi-part one) from `src/utils/define-recipe.ts`. They check variants, slots and style values against your tokens, so typos fail in the recipe file.
3. Register the recipe in `panda.config.ts`: single recipes under `theme.recipes`, slot recipes under `theme.slotRecipes`.
4. Run `bun run codegen`, then export the component from `src/index.ts`.

`button` and `card` are the templates to follow.

## Testing and accessibility

Stories double as tests through Vitest and the Storybook Vitest addon. The a11y addon is set to `error`, so accessibility violations fail the story tests.
